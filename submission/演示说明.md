# LabelHub 可访问演示环境说明

本文档用于说明 LabelHub 当前可访问的线上演示环境、账号获取方式、推荐演示路线和提交材料位置。它面向评审、验收人员和现场演示人员，重点回答“从哪里进入、按什么顺序看、哪些资料对应哪些能力”。

本文档不写入生产密码、数据库口令、Redis 口令、Turnstile secret key、LLM API Key 或其它敏感配置。

## 1. 演示环境概览

当前系统已经部署到生产环境，并通过 HTTPS 子路径对外访问：

1. 前端入口：`https://www.scu-gpt.top/labelhub/`
2. 登录入口：`https://www.scu-gpt.top/labelhub/login`
3. 注册入口：`https://www.scu-gpt.top/labelhub/login#signup`
4. 文档中心：`https://www.scu-gpt.top/labelhub/docs`
5. 关于页面：`https://www.scu-gpt.top/labelhub/about`

部署说明：

- 系统部署在 `/labelhub/` 子路径下，不是根域名独占部署。
- 浏览器访问 `/labelhub/`，静态资源由前端容器提供。
- 浏览器调用 `/labelhub/api/`，由宿主机 Nginx 反向代理到后端 `/api/`。
- 登录、注册和邀请注册均需要通过 Cloudflare Turnstile 人机验证。
- 生产登录页不展示本地开发用的演示账号入口。

推荐访问环境：

- 推荐使用 Chrome 或 Edge 桌面端浏览器。
- Owner 的模板设计、批量配置、看板和导出建议使用桌面端。
- 移动端可用于浏览、轻量标注和状态确认，但不是主要演示视口。

## 2. 账号与访问方式

生产环境不在公开提交包中写入账号密码。演示账号和密码应通过现场评审、私有渠道或部署负责人单独提供。

账号来源说明：

1. Owner 账号
   - 用于任务负责人后台。
   - 由部署初始化流程创建，或由已有 Owner 通过邀请注册创建。
   - 可管理数据集、模板、任务、AI 规则、模型配置、审核、看板和导出。

2. Labeler 账号
   - 用于标注员工作台。
   - 可通过注册入口创建普通 Labeler 账号。
   - 可领取任务、填写结构化表单、保存草稿、提交答案和处理打回项。

3. Reviewer 账号
   - 用于人工审核员工作台。
   - 由 Owner 创建 Reviewer 邀请后，通过邀请链接或邀请码注册。
   - 可查看 AI 审核任务、进入审核工作台、执行通过、打回或争议裁决。

4. AI Reviewer / Agent
   - AI Reviewer 是 Web 端的 AI 预审管理视角。
   - `system_agent` 是后台机器账号，只供独立 Agent 服务登录后端领取 AI Review Job。
   - `system_agent` 不建议作为普通 Web 演示账号使用。

演示前建议确认：

- 已准备至少一个可登录的 Owner 账号。
- 如需现场完整闭环，提前准备一个 Labeler 账号和一个 Reviewer 账号。
- 如需演示 AI 预审，确认 Agent 容器正在运行，且模型配置可用。
- 若使用新注册 Labeler，需要先通过登录页注册并完成人机验证。
- 若使用新 Reviewer，需要先由 Owner 创建邀请，再完成邀请注册。

## 3. 推荐演示路线

建议按“Owner 准备任务 -> Labeler 标注 -> AI 预审 -> Reviewer 复核 -> Owner 看板与导出”的顺序演示。这样能覆盖系统最完整的业务闭环。

### 3.1 Owner 准备项目

演示入口：

- `https://www.scu-gpt.top/labelhub/owner/datasets`
- `https://www.scu-gpt.top/labelhub/owner/templates`
- `https://www.scu-gpt.top/labelhub/owner/tasks`

推荐步骤：

1. 进入数据集页面，查看或创建数据集。
2. 导入少量 JSON、JSONL、CSV 或 XLSX 样本。
3. 进入模板页面，查看已有模板或创建新模板。
4. 在模板设计器中展示动态 Schema 能力，例如文本、单选、多选、JSON、附件、展示项、多 Tab 或 LLM 触发组件。
5. 发布模板。
6. 创建任务，绑定数据集和模板。
7. 配置任务范围、标注员、审核员、题量、AI 规则和截止时间。
8. 发布任务。

重点展示：

- 数据集导入和预览。
- 模板设计器和动态表单。
- 任务发布前的范围、人员和题量配置。
- Owner 对任务生命周期的控制。

### 3.2 Labeler 标注作业

演示入口：

- `https://www.scu-gpt.top/labelhub/labeler/market`
- `https://www.scu-gpt.top/labelhub/labeler/my-tasks`
- `https://www.scu-gpt.top/labelhub/labeler/drafts`
- `https://www.scu-gpt.top/labelhub/labeler/returned`

推荐步骤：

1. 使用 Labeler 账号登录。
2. 进入任务市场，领取 Owner 发布的任务。
3. 进入我的任务，打开答题页。
4. 展示题目原始内容和按 Schema 渲染的结构化表单。
5. 填写部分字段并保存草稿。
6. 从草稿箱返回继续编辑。
7. 如模板配置了 LLM 辅助或字段级 LLM 触发，演示获取建议并人工确认应用。
8. 提交答案。

重点展示：

- 任务市场领取流程。
- 动态 Schema 答题页。
- 草稿保存与恢复。
- LLM 助手对标注过程的辅助。
- 提交后进入 AI 预审或人工审核链路。

### 3.3 AI Reviewer 与 Agent 预审

演示入口：

- `https://www.scu-gpt.top/labelhub/ai-reviewer`
- `https://www.scu-gpt.top/labelhub/ai-reviewer/queue`
- `https://www.scu-gpt.top/labelhub/ai-reviewer/settings/model`
- `https://www.scu-gpt.top/labelhub/owner/ai-review`

推荐步骤：

1. 在 AI 预审规则页面查看规则、Prompt、评分维度和阈值。
2. 在模型配置页面查看当前 active 模型配置。
3. Labeler 提交答案后，观察 AI Review Job 进入队列。
4. 等待 Agent 领取 Job，并查看状态从 pending/running 推进到 completed 或 failed。
5. 查看 AI 返回的 decision、score、comment、risk flags 和 evidence。
6. 如 Job 失败，可展示失败摘要和重试入口。

重点展示：

- AI 预审规则和模型配置由 Web 管理。
- Agent 独立异步执行，不阻塞 Labeler 提交。
- AI 输出为结构化结果，可供 Reviewer 和看板复用。

注意事项：

- AI 预审依赖 Agent 服务和外部模型供应商。
- 如果模型供应商暂时不可用，Job 可能进入 failed，可通过失败摘要说明链路已经闭环。
- Agent 机器账号不作为普通 Web 演示账号使用。

### 3.4 Reviewer 人工复核

演示入口：

- `https://www.scu-gpt.top/labelhub/reviewer`
- `https://www.scu-gpt.top/labelhub/reviewer/ai`
- `https://www.scu-gpt.top/labelhub/reviewer/disputes`

推荐步骤：

1. 使用 Reviewer 账号登录。
2. 进入 AI 审核任务列表。
3. 打开某个任务的审核工作台。
4. 同屏查看题目原始内容、Labeler 答案和 AI 建议。
5. 执行通过、打回或争议裁决。
6. 查看题目时间线，确认提交、AI 预审和人工审核事件可追溯。
7. 如选择打回，切换回 Labeler 查看打回项并返工。

重点展示：

- 三栏审核工作台。
- AI 结果辅助人工判断。
- 打回、争议和通过裁决。
- 审核时间线和审计记录。

### 3.5 Owner 回看与交付

演示入口：

- `https://www.scu-gpt.top/labelhub/owner/review`
- `https://www.scu-gpt.top/labelhub/owner/dashboard`
- `https://www.scu-gpt.top/labelhub/owner/export`

推荐步骤：

1. 回到 Owner 账号。
2. 查看审核管理中的任务进度、审核员负载和题目时间线。
3. 打开数据看板，查看任务进度、质量指标、审核分布、争议数据和到期风险。
4. 进入导出中心，创建导出任务。
5. 选择 JSON、JSONL、CSV 或 XLSX 格式。
6. 下载导出文件，检查结果中包含题目、答案、AI 结果和人工审核结果。
7. 确认下载状态回写。

重点展示：

- Owner 对项目状态和质量的集中查看。
- 审核链路可追溯。
- 标注和审核结果可导出交付。

## 4. 推荐最小演示闭环

如果演示时间较短，建议按下面 8 步走完最小闭环：

1. Owner 登录。
2. Owner 创建或选择数据集。
3. Owner 创建或选择模板。
4. Owner 创建并发布任务。
5. Labeler 领取任务并提交标注。
6. Agent 完成 AI 预审或展示 AI Job 状态。
7. Reviewer 完成人工审核。
8. Owner 查看看板并导出结果。

该闭环能覆盖平台最核心的价值：任务配置、协作标注、AI 预审、人工复核和结果交付。

## 7. 验收注意事项

1. 账号安全
   - 本提交包不公开生产账号密码。
   - Owner 账号、Reviewer 邀请和必要的演示账号应通过私有渠道提供。
   - 不建议在公开文档中写入任何可直接登录的生产凭据。

2. 人机验证
   - 登录和注册需要 Turnstile 人机验证。
   - 若浏览器插件或网络策略拦截 Turnstile，可能导致登录或注册无法提交。

3. AI 预审
   - AI 预审依赖 Agent 服务、模型配置和外部模型供应商。
   - 如果外部模型服务超时或失败，可在 AI Job 队列中查看失败状态和摘要。
   - 人工 Reviewer 是最终裁决者，AI 结果作为辅助依据。

4. 子路径部署
   - 线上访问路径必须带 `/labelhub/`。
   - 深层路由刷新应正常回退到前端应用。
   - 前端 API 请求应使用 `/labelhub/api` 前缀。

5. 文件与导出
   - 数据集导入、附件上传和导出下载均受后端与 Nginx 的文件大小限制约束。
   - 大文件建议拆分导入或按后续对象存储方案扩展。

6. Swagger 与接口调试
   - Swagger UI 主要用于本地或内网调试。
   - 公开演示以 Web 页面和生产 API 代理路径为准。
   - 接口细节以 `submission/API文档/接口文档.md`、Swagger/OpenAPI 和当前 Controller 实现为准。

## 8. 现场演示建议

正式演示时建议控制节奏：

1. 先用公开首页说明平台定位和角色闭环。
2. 用 Owner 账号展示数据、模板和任务准备。
3. 切换 Labeler 展示领取、答题和提交。
4. 展示 AI Job 队列或 AI 审核结果。
5. 切换 Reviewer 展示人工裁决。
6. 回到 Owner 展示看板、审计和导出。
7. 最后打开 `关键技术点.md`，说明动态 Schema、状态机、Agent 和生产部署等实现亮点。

演示过程中应避免展示生产 `.env`、数据库连接信息、模型 API Key、Turnstile secret key 和其它敏感配置。
